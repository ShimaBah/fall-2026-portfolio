# Site Screening with ModelBuilder (GISY5004, Assignment 3)

ModelBuilder workflow in ArcGIS Pro for 9 sites (3 site sets), submitted 24 October 2026.

Workflow: Buffer by BUFF_DIST, overlay with forest / soil / county layers, Frequency summary, area in hectares, 9 sketch maps.
