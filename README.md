## Projects

### 1. Newfoundland Weather Stations, 1871-2026 — #30DayMapChallenge Day 10
341 weather stations in Newfoundland, from Environment Canada Station Inventory. Colour = when a station started, bigger dot = ran for longer. Oldest: Belle Isle, 1871. Longest: Port aux Basques, 108 years. 50 still active in 2026.
- Source: map and Python code in `gdaa1001-nl-weather-stations/` in this repo.

### 2. GDAA 1001 Project 1 — Newfoundland Weather Stations (R)
ETL in R: download the Environment Canada Station Inventory by code, keep only Newfoundland (341 stations, 8,637 in Canada), clean it into tidy spatial data, EPSG:4326. Submitted Nov 12, 2026.
- Source: same dataset as Project 1 above, in `gdaa1001-nl-weather-stations/` in this repo. The R Notebook file itself is on Shima's laptop and will be added here when she sends it.

### 3. Wildlife Analysis with Survey123
Built and tested Survey123 surveys (Wildlife Check and Wildlife Summary). Mapped a demo moose point in ArcGIS Online against government Moose Management Areas. 6 summary records, 1980-2014.
- Source: `wildlife-analysis/` and `wildlife-check/` in this repo.

### 4. Terra Nova River Monthly Flow — Live App
R Shiny app for HYDAT daily flow at Terra Nova River, Glovertown (02YS005), 1985-2024, averaged by month. Python ETL (pandas) for the same data; live app fetches in R, published on Posit Connect Cloud.
- Source: `shiny-app/` in this repo.
