# GNSS Datum Transformation — 165 RTK Points (GEOM5005, Assignment 3)

165 RTK points transformed from ATS77 / CGVD28 to NAD83 CSRS 2010.0 / CGVD2013, in metres.

Method, in batch mode:
- NTV2 (horizontal): Grid NS778302, Coverage Nova Scotia, From ATS77 To NAD83(CSRS) 2010, Coordinates Projection, Zone NS-NAD83-2010-5.
- GPS-H (heights): Convert, Conversion HT2_2010_to_CGG2013a, Reference Frame NAD83(CSRS).

Files in this folder:
- `NTV2Output_ShimaBahramnejad.csv` — NTV2 horizontal transformation output.
- `GPS-H_Output_ShimaBahramnejad.csv` — GPS-H height transformation output.
- `PRKLOT_NAD83_transformed.csv` — transformed points (Easting, Northing, Elevation).
