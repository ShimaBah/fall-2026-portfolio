# Shiny App — Engine size vs horsepower

A tiny R Shiny app, built Nov 2, 2026, from my own GDAA1001 disp vs hp scatterplot.

## Live app
Published on Posit Connect Cloud, public:
https://connect.posit.cloud/shimabahramnejad/content/01a19c64-4e47-30c7-7834-0bcd53e62864

## Code
`app.R` — the whole app, in one file.

It shows one plot: Displacement (disp) on the bottom, Horsepower (hp) on the side.
The data is `mtcars`, built into R. No other data is used.

## Run it locally
In RStudio, open `app.R` and click Run App. The `shiny` package is needed.
