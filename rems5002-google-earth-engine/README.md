# Satellite Image Analysis in Google Earth Engine (REMS5002, Lab 2)

Google Earth Engine JavaScript code, submitted 29 October 2026 as part of REMS5002 Lab 2 (with a 14-slide presentation).
Areas: Lawrencetown / COGS, Nova Scotia, and Sanandaj, Iran.

These are Google Earth Engine Code Editor snippets, not standalone scripts — some parts use variables defined earlier in the Lab 2 script (for example the study-area geometry and image collections).

- `code-part-a.js` — Sentinel-2: true-colour and false-colour composites, NDVI.
- `code-part-a-hometown.js` — Sentinel-2 NDVI, leaf-on and leaf-off, for the hometown area.
- `code-part-b.js` — SRTM DEM: elevation, hillshade, slope, mean elevation.
- `code-part-c.js` — Landsat 8: median composite, NDVI, GreenestPixel composite.
- `code-part-d.js` — MODIS EVI: reference period vs recent period, cumulative anomaly.
- `code-part-e.js` — Landsat 8: cloud masking, NDWI, water inundation frequency.
- `code-part-f.js` — RESOLVE ecoregions: painted outlines and fills.
- `code-part-g.js` — Legends and Landsat 8 time-lapse presentation material.
